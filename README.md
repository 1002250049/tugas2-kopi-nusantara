# Kopi Nusantara — Halaman Katalog Produk

Implementasi antarmuka halaman katalog produk kopi lokal menggunakan HTML5 semantik, CSS3 (dengan *custom properties*), dan JavaScript murni (*Vanilla JS*).

## Struktur Proyek
```text
├── index.html   # Struktur semantik utama (header, main, section, article, footer)
├── styles.css   # Styling responsif menggunakan CSS custom properties
├── script.js    # Logika interaktif (toggle menu, filter produk, keranjang, validasi form)
└── README.md    # Dokumentasi proyek
